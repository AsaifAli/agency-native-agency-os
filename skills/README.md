# Curated Agent Skills

This directory contains reviewed, repository-owned adaptations in the Agent Skills SKILL.md format.

- Catalog and pinned source provenance: catalog.json
- Admission and runtime policy: ../docs/SKILLS_AND_SKILL_GOVERNANCE.md
- Skills are disabled by default, tool-free, and restricted to public/synthetic data.
- The authenticated API exposes metadata first and full instructions only on explicit detail requests.
- No skill can grant tools, permissions, provider-side execution, or approval authority.

Do not copy upstream scripts, hooks, assets, or full skill directories without reviewing the exact source revision, license, security implications, and data-flow requirements.
