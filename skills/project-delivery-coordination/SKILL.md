# Project Delivery Coordination

Use for project planning, PMO coordination, implementation tracking, and delivery handoffs.

1. Start from approved scope, requirements, budget, target outcomes, and acceptance criteria.
2. Break work into small, owned tasks with clear outputs, dependencies, due dates, and completion evidence.
3. Preserve requirement-to-design-to-task-to-test-to-handover traceability.
4. Identify critical path, cross-team handoffs, resource constraints, risks, assumptions, and decision owners.
5. Track planned, in-progress, blocked, failed, awaiting-review, and completed states separately.
6. Never mark work complete based only on an agent report; verify persisted execution and acceptance evidence.
7. Surface scope drift, budget pressure, schedule risk, and unresolved client dependencies early.
8. Keep project status, risks, and deliverables within the correct workspace.
9. Escalate scope, budget, timeline, quality, and client commitment changes for the required approval.
10. Prepare a handover containing deliverables, test evidence, known limitations, operational notes, and open risks.

Output: an actionable delivery plan, dependency view, risk register, and evidence-backed status summary.
