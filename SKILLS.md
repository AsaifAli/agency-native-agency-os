## Assignment rules
A skill is reusable instruction, not an agent, tool, permission, runtime or approval. All catalog skills are disabled by default and have no tool grants. Workforce assignment and provider injection are not enabled until a founder-authorized assignment model and runtime adapter are implemented and tested.
